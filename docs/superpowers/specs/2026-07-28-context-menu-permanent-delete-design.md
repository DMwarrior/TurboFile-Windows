# 右键永久删除设计

## 目标

在普通文件列表和图片网格的右键菜单中新增“永久删除”，对当前选中的一个或多个文件、文件夹直接执行永久删除，不进入极速传回收站。普通“删除”仍移动到回收站，剪切、拖拽移动、传输完成后的源文件清理及回收站内部操作均保持现状。

## 已确认规则

- 普通文件列表与图片网格都提供“永久删除”。
- 右键命中未选中项目时先切换为该项目；命中已选中项目时对完整多选集合生效。
- 菜单项放在普通“删除”之后，使用危险操作样式。
- 执行前必须弹出中文强确认：“永久删除选中的 N 个项目吗？此操作无法撤销，且不会进入回收站。”
- 本机 Windows 继续使用现有原生永久删除实现。
- Linux/SSH 永久删除直接使用 `sudo -n rm`，不先尝试普通 `rm`，也不做失败后的二次重试。
- `sudo -n` 禁止交互式密码提示；设备未配置免密 sudo 时立即失败并显示明确错误，不能让任务无限等待。
- 只有本次新增的普通视图“永久删除”入口启用 sudo。普通删除到回收站、剪切清理、传输清理和已有内部删除调用不改变。
- 不递归预扫描文件夹大小，不引入额外 SSH 探测，不改变传输协议、并发或速度。

## 实现边界

### 界面

文件列表复用现有右键菜单和选中项模型，新增“永久删除”动作。图片网格补齐与文件列表一致的右键菜单入口，至少包含“删除”和“永久删除”，并复用图片网格现有多选状态。

永久删除确认后立即创建任务日志。成功时刷新当前侧目录和图片网格；失败时重新刷新以恢复可能被乐观移除的项目。左右面板状态相互独立。

### 服务接口

复用现有高性能批量删除核心，但增加一个只由新入口传入的“直接提权删除”选项。默认值保持关闭，确保所有现有调用行为不变。

- 本机 Windows：沿用当前本机批量删除路径。
- 远程 Windows：沿用当前远程 PowerShell 删除路径。
- POSIX SSH：启用该选项时，批量命令直接执行 `sudo -n -- rm -rf -- ...`；未启用时仍执行现有命令。

路径继续使用现有安全转义、批处理和任务队列，避免命令注入与参数过长。不得把所有路径拼成一个无限长命令。

### 错误处理

- 用户取消：不创建删除命令，不刷新为成功状态。
- 免密 sudo 不可用：任务失败，中文错误说明需要为该设备配置免密 sudo；不退回普通 `rm`。
- 部分批次失败：保留失败项目并报告失败，不把整个任务误报为成功。
- SSH 断开或命令异常：沿用现有任务失败和连接恢复机制，不自动改走回收站。

## 测试计划

先增加会失败的静态/单元测试，再实现功能：

- 文件列表普通视图右键菜单包含“永久删除”，且普通“删除”仍调用回收站。
- 图片网格右键菜单包含“删除”和“永久删除”，并作用于完整选择集合。
- 取消确认时不调用删除服务。
- 确认后调用永久删除路径并传入直接提权选项。
- POSIX SSH 提权路径直接生成 `sudo -n` 删除命令，不先执行普通 `rm`，也没有重试。
- 未启用提权选项的现有删除调用保持原命令和行为。
- Windows 本机与远程 Windows 不受 Linux sudo 选项影响。
- 批量路径继续分批，特殊字符路径安全转义。
- 成功与失败后均刷新正确面板，另一侧不刷新。

## 非目标

- 不新增工具栏永久删除按钮。
- 不新增 Shift+Delete 快捷键。
- 不改变回收站内已有永久删除和清空回收站行为。
- 不为 sudo 输入、保存或传递密码。
- 不修改普通删除、剪切、拖拽、传输协议和传输进度逻辑。
