# 复制/剪切模式紧凑图标设计

## 目标

将当前工具栏中横向排列的“独立图标＋文字＋外层长方形边框”改成与其他工具栏图标相同大小的紧凑控件。文字直接显示在图标框内部，不再占用额外横向空间。

## 视觉结构

- 外层按钮固定为标准工具栏尺寸 `24×24px`，与刷新、搜索等按钮一致。
- 外层按钮不显示边框、轮廓或选中高亮。
- 按钮内部只有一个约 `24×18px` 的小方框图标。
- 小方框内部居中显示完整中文“复制”或“剪切”。
- 删除现有独立文件图标、剪刀图标以及图标右侧的文字。
- 悬停继续使用工具栏原有的轻微背景反馈，不增加长方形描边。

## 颜色

- 复制模式：青绿色，使用清晰的主题色并保证深色、浅色主题下可见。
- 剪切模式：亮红色，避免现有剪切状态过暗。
- 颜色同时应用于内部小方框边线和文字。
- 点击切换时只改变文字与颜色，不改变控件尺寸和位置。
- 高对比度主题允许使用系统对比色，以保证可访问性。

## 行为

- 默认仍为复制模式。
- 点击后在复制和剪切之间切换，左右面板继续保持各自独立状态。
- 不改变拖拽复制、拖拽剪切、同侧移动以及失败时不删除源文件等传输逻辑。
- 不显示持续选中轮廓；键盘聚焦时仍保留浏览器必要的可访问性焦点提示。

## 验证

- 检查按钮外层尺寸与相邻工具栏图标一致。
- 检查复制和剪切文字完整位于内部小方框内。
- 检查不存在独立文件/剪刀图标和外部长方形边框。
- 检查复制为青绿色、剪切为亮红色，并在深浅主题下清晰可见。
- 检查左右面板模式仍独立，点击切换不造成工具栏位移。
