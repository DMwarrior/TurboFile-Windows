# 图片原始尺寸显示修复设计

## 目标

远程 SSH 图片生成缩略图后，图片网格和单图预览始终显示原图尺寸。例如原图为 `2048×512`、缩略图为 `128×32` 时，界面必须显示 `2048×512`。

## 设计

- 保持现有批量缩略图 SSH 命令、并发数和可视区加载策略不变。
- 在同一个批量返回帧中增加 `originalWidth` 和 `originalHeight`，不增加 SSH 往返、目录预扫描或原图传输。
- 只有远端实际转码缩略图时才读取原图尺寸；原图直接返回时继续使用浏览器自然尺寸。
- 界面将批量结果中的原图尺寸保存到 `originalWidth/originalHeight`，显示逻辑继续优先使用这两个字段。
- 远端无法识别尺寸时保留 `undefined`，绝不把无效值当成原图尺寸；图片加载本身不受影响。

## 性能约束

- 正常批量路径仍然只有一次 SSH 命令。
- 每张图片仅增加两个整数文本字段。
- 不调用 `readImageMetadataBatch`，不恢复目录级图片头扫描。
- 不改变缩略图质量、宽度、加载批次或并发数量。

## 验证

- 回归覆盖 `2048×512` 原图与 `128×32` 缩略图。
- 验证原图直传、转码成功、转码失败回退及未知尺寸。
- 运行 TypeScript 编译检查和图片相关单元测试。
