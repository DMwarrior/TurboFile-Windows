# 极速传 1.174.0

发布日期：2026-10-29

- 设备管理新增“导入已有设备”按钮，自动扫描本机保存的 SSH 连接，选择需要的设备后批量添加。
- 支持 OpenSSH 的 `.ssh/config` 和 `Include` 配置，以及 WinSCP、PuTTY/KiTTY 保存的 SSH 会话；列表显示地址、用户、端口、配置来源和凭据状态。
- 支持迁移 WinSCP 普通保存密码及私钥路径，密码存入极速传加密凭据存储，不在列表或日志中显示明文。
- 重复导入时保留现有设备和密码，仅补充缺失凭据；新设备凭据保存失败时不留下不完整配置。
- 保留手动选择 WinSCP INI 文件入口，支持中文名称、非标准端口及默认目录。

兼容性说明：WinSCP 主密码保护的凭据需单独填写。代理、跳板机、OpenSSH Match 条件和特殊 Agent/证书配置暂不自动迁移，会在导入结果中提示。`known_hosts` 不包含完整登录信息，不作为完整设备导入。识别过程不执行配置中的命令，也不读取私钥文件内容。

Windows x64 安装包：`TurboFileSetup-win32-x64-1.174.0.exe`
