# 极速传 1.172.0 内测说明

日期：2026-10-22。基于 1.171.0，仅生成本地 Windows x64 安装包。

## 本次改动

- 任务日志改为应用级持久保存，关闭传输页、关闭窗口或重启软件后仍可查看。
- 仅记录实际复制、剪切、传输、移入回收站和永久删除任务；普通复制到剪贴板、重命名、新建目录和文件编辑不写入任务日志。
- 日志仅展示摘要卡片，包括操作结果、时间、来源与目标、项数、字节、耗时和最终传输方式；失败时保留简短原因。移除展开明细、逐项清单、导出、筛选及统计等功能。
- 日志在共享进程中异步批量写入，限定队列和单条记录大小；按保留时长、5000 条摘要保留目标及 10 MiB 容量预算清理旧记录。已有详细日志升级时保留摘要并回收明细占用。
- 修复反复关闭、打开日志页后，任务已保存但新摘要不自动显示的问题。
- 设备页和日志页中间区域沿用传输页背景，与左侧栏通过背景及边界区分，适配深浅色模式。
- 保留 1.171.0 已有传输与设备排序功能，以及安装器默认勾选桌面快捷方式的修复。

本次未改变传输协议、并发、分块或数据通道；日志仅采集任务开始和结果，不新增传输前扫描或逐字节写盘。近期提出的设备状态文案、测试连接按钮、长路径提示、时间格式和日志卡片局部刷新等建议尚未实现，不包含在本次版本中。

## 内测重点

1. 在左右两侧发起实际复制或剪切，检查日志中的来源、目标和结果。
2. 执行移入回收站及永久删除，检查任务记录；普通重命名、新建目录不应新增日志。
3. 反复关闭、打开日志页，再发起复制或删除，确认摘要自动出现。
4. 关闭传输页和软件后重新打开，确认已有记录仍保留。
5. 切换深浅色模式，核对设备页和日志页与侧栏的背景层次。
6. 安装时检查“创建桌面快捷方式”默认勾选，仍可手动取消。

本地安装包和 SHA-256 校验文件位于 `.build/win32-x64/`。本次仅提交本地 Git 并打包，不推送仓库、不上传 Release、不修改公开更新清单。
