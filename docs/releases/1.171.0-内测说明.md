# 极速传 1.171.0 内测说明

日期：2026-10-19。基于 1.170.0，仅生成本地 Windows x64 安装包，暂不公开发布。

## 本次改动

- 设备支持拖动排序，重启后保留；设备管理与左右面板的设备列表使用相同顺序。
- 加强 SSH/SFTP 回调、连接关闭、任务挂起及取消处理。原生 POSIX 复制/移动取消时，核验并停止本任务的远端进程组，再确认取消；无法确认停止时报告失败。
- 保留实际传输错误及协议切换原因；权限不足、空间不足、文件冲突、源文件变化等错误停止无意义回退。
- 修复同机大文件字节统计超过 2 GiB 后被清零的问题，补充同机移动的实际字节与速度反馈；展开终端或缩窄窗口时仍显示速度和取消按钮。保持原有横向进度条显示方式。
- 修复同侧复制/剪切后切换目录粘贴时的快捷键归属、焦点及目标面板识别，并处理旧剪切任务清除新剪贴板的问题。
- 删除独立外观页面，五项字体设置迁移到“视图 → 字体”，已有配置继续生效。
- 交互式安装默认勾选“创建桌面快捷方式”，允许手动取消；静默更新及显式任务参数继续遵循原有选择。

传输协议体系、并发数、分块、缓冲及原生 cp/reflink 参数保持原有配置，未增加传输前的目录扫描。本次不包含此前讨论的刷新保留操作现场、重试固定原目标、同步预览局部更新或完整文件拖拽流程改造。

## 内测重点

1. 拖动设备顺序后重启，检查顺序及连接配置。
2. 同一侧复制或剪切，进入同一服务器的其他目录后粘贴，分别检查左侧、右侧和覆盖操作。
3. 同机复制大于 2 GiB 的目录，展开终端，检查速度、字节和耗时；缩窄窗口后检查速度与取消按钮。
4. 在复制/跨文件系统剪切期间取消，确认任务结束、目标不再增长及源文件状态，然后再次传输。
5. 在“视图 → 字体”调整五项设置。

同一文件系统内瞬间完成的移动通常只更新目录项，不会虚构数据传输速度。快速完成且总量未知的批量任务可能在首个采样前结束。不同远端系统的取消及进程观察能力存在差异，详细边界与已有实机验证见 [五项修复验证记录](../validation/2026-10-14-five-fixes.md)。

本地安装包和 SHA-256 校验文件位于 `.build/win32-x64/`。本次不执行 Git 推送、Release 上传或公开更新清单写入。
