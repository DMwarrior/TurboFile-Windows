# 极速传 1.173.0

- 修复同名文件标签追加长路径的问题，恢复只显示文件名，悬停仍可查看完整路径。
- 恢复文字更新按钮，下载时显示实际百分比；服务器未提供总大小时显示已下载容量，避免只显示省略号。
- 保留 1.172.0 的悬停更新内容与离线版本历史。
- 修复持续下载时进度更新被反复推迟的问题，刷新进度时保留按钮和悬停内容。
- 更新下载优先使用国内分片，增加断点续传、已完成分片复用、有限重试与停滞超时；网络恢复后减少重复下载。
- 保留大小与 SHA-256 校验，以及应用原有代理配置；每次只使用一个更新下载连接。
- 发布流程要求国内安装包验证通过后，再发布包含国内分片的更新清单；GitHub 作为备用源。

这些修改仅作用于编辑器标签和应用更新下载，不调整 SSH/SFTP/SCP/Tar/Rsync 文件传输数据路径。
