# 极速传 1.173.0

2026-10-23 修订发布：覆盖原 1.173.0 安装包，版本号保持不变。已安装旧 1.173.0 的用户请重新下载安装修订包。

- 修复同名文件标签追加长路径的问题，恢复只显示文件名，悬停仍可查看完整路径。
- 恢复文字更新按钮，下载时显示实际百分比；服务器未提供总大小时显示已下载容量，避免只显示省略号。
- 保留 1.172.0 的悬停更新内容与离线版本历史。
- 下载进度按真实字节每 250 毫秒刷新，显示一位小数，悬停可查看已下载和总容量。
- 更新下载优先国内源，安装包按 32 MiB 分片，最多同时下载两个独立分片；保留已完成分片复用、有限重试、停滞超时和服务器支持时的断点续传。
- 取消或失败时结束实际网络连接，避免无效下载继续占用带宽；保留大小与 SHA-256 校验及应用原有代理配置。
- 修复安装和启动时强制结束 Windows 资源管理器的问题。拖拽扩展按版本隔离存放，升级无需关闭任务栏、桌面或已打开的资源管理器窗口。
- 复用已下载的安装包前重新校验，避免同版本修订时使用旧缓存。
- 发布流程要求国内安装包验证通过后，再发布包含国内分片的更新清单；GitHub 作为备用源。

这些修改作用于编辑器标签、应用更新和 Windows 拖拽扩展的安装注册，不调整 SSH/SFTP/SCP/Tar/Rsync 文件传输数据路径。
