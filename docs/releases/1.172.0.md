# 极速传 1.172.0

发布日期：2026-10-23

- 任务日志持久保存复制、传输和删除记录，关闭页面和重启后仍可查看；精简摘要、限制容量，恢复顶部状态统计。
- 底部新增轻量设备监控，跟随当前面板显示 CPU、内存及当前目录所在磁盘的已用和总容量，固定数据区域以减少跳动。
- 统一左侧栏宽度和设备图标，修复设备、日志页面底部留白；设备下拉列表充分利用可用高度。
- 改善浅色模式文字和图标的可读性，恢复默认“新标签页”名称。
- 安装器默认勾选创建桌面快捷方式。
- “帮助”右侧改用更新图标，悬停显示可更新版本及主要改动；“帮助 → 更新日志”从本版本开始保留版本记录。
- GitHub、Gitee 统一公开完整源码和安装包入口，不再分别维护源码仓库和展示仓库。

设备监控使用独立采集连接、缓存和超时退避；本次更新入口仅复用已有更新检查结果。未增加传输数据路径中的日志或监控处理。
