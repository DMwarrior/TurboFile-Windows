# 极速传 1.175.0

发布日期：2026-11-08

- 底部传输信息可展开进度面板，显示实时速度曲线、已传容量、耗时和完成后的平均速度；再次点击、最小化或关闭面板后继续传输。
- 已知总量显示真实百分比和预计剩余时间；未知总量显示传输活动，不为显示进度额外扫描目录大小。进度条平滑更新，不含粒子特效。
- 增强 SFTP 覆盖文件保护，先写同目录临时文件，完成后再替换；断线、取消或写入失败时保留已有目标文件。
- 修复跨盘剪切在源清理失败后误删目标副本的问题，加强目录剪切时对传输期间新增或修改文件的保护。
- 完善传输取消、Tar 中转结束确认和错误传播，避免失败后错误重试或误报完成。
- 设备编辑保存失败时恢复原配置与凭据；任务日志临时写入失败后进行有容量上限的退避重试。
- 统一左右路径显示和工具栏图标尺寸，调整图标配色，改善深浅主题下的可读性。

Windows x64 安装包：`TurboFileSetup-win32-x64-1.175.0.exe`

自动更新继续优先使用 Gitee 国内源，GitHub 提供完整 EXE 下载和备用更新源。

目录剪切只核对文件元数据，不计算内容哈希。若源文件在传输中发生变化，或服务器无法提供足够精度的元数据，已复制的目标文件保留，未能安全确认的源文件也会保留，并提示剪切未全部完成。
